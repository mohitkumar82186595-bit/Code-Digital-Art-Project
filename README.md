# Code-Digital-Art-Project
## 🚀 Turning Code Into Digital Art ✨

What if **code could become art?** 🤯

I built this interactive **Code → Digital Art** experience using **HTML, CSS & JavaScript**.

✨ 1,800+ dynamic code particles
🧠 Particles intelligently form a digital butterfly
🖱️ Interactive mouse-based distortion
💥 Click-to-explode particle effect
🔗 Dynamic particle connections
🌌 Futuristic holographic atmosphere
⚡ Real-time animation using Canvas API
📱 Responsive experience

The most satisfying part is watching hundreds of individual code characters transform into a single piece of digital art.

This project is a reminder that **creative coding isn't just about writing code — it's about turning logic into experiences.** 💻🎨

Built with:
**HTML5 • CSS3 • JavaScript • Canvas API**
